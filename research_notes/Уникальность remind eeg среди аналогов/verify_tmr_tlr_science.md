# Verification of `tmr_tlr_science.md` (adversarial fact-check)

**Purpose.** This file confirms or corrects the factual claims in `tmr_tlr_science.md` (same folder). Where a row says CORRECTED, the report writer must use the corrected statement from this file, not the wording in the notes. Where a row says CONFIRMED, the notes may be quoted as written (subject to the "misleading in context" list at the end).

**Method.** Checked 2026-10-21. Each claim was verified against the URL the notes cite, or, when that URL was blocked (403/503/bot wall), against the same article via PMC/Europe PMC, Crossref/DataCite/OpenAlex, the bioRxiv API or the GitHub API. WebSearch was not used. 16 primary claims were selected (numbers, attributions, categorical "none exists" claims); 6 further spot checks are listed afterwards. Verdicts: CONFIRMED / CORRECTED / UNVERIFIED.

**Score.** 16 primary claims: 13 CONFIRMED, 3 CORRECTED (all minor), 0 UNVERIFIED. No correction reverses a conclusion of the notes; one inference (Hu 2020 "unspecified" stage) is technically true but overstated, see the last section.

## Technically true but misleading in context

1. **Hu 2020 "unspecified" stage → "EEG-supervised gating is an evidence-based differentiator" (KQ1 inference, KQ9 first bullet).** The category is correctly defined as cueing without EEG monitoring, and its pooled g (0.26) is indeed non-significant. But it rests on k = 6 effect sizes from 4 experiments (N = 140) with CI [−0.11, 0.62]; the point estimate equals the SWS estimate (0.27), so the non-significance reflects low power, not evidence of no benefit. Corrected phrasing: "In Hu 2020 the four experiments that cued without EEG monitoring showed a pooled g of 0.26 that was not significant (wide CI, k = 6); this is consistent with, but does not demonstrate, an advantage of EEG-verified stage targeting."
2. **"REM-only triggering" in quotation marks (KQ3, KQ9).** Paraphrase of Konkoly 2024's "an obvious improvement would be to trigger cues only when an individual is in REM sleep." Keep the point, drop the quotation marks.
3. **Salfi 2025 as "first home closed-loop TMR with a consumer EEG headband".** True for declarative/vocabulary TMR, but the same headband had already been used for home REM TMR by Schwartz 2022 and Borghese 2022, which Salfi cites. State "first wearable-EEG replication of declarative TMR outside the lab".
4. **Konkoly 2021 cited as TLR evidence ("TLR ... supports real-time two-way communication", KQ3 takeaway).** The paper is about two-way communication in lucid REM across four labs; only the Northwestern arm used auditory lucidity cues. Cite it as evidence that cue-induced lucid REM can support communication, not as a TLR induction result.
5. **Whitmore & Paller 2023 "convenience sample, not preregistered" (KQ6).** Preregistration status is not stated in the article; "not preregistered" is an inference, not a reported fact.
6. **Picard-Deland/Dresler 2024 "first preregistered multi-center PSG study".** The preregistration is asserted in the v2 title (Aug 2026); the study remains a preprint with no published DOI as of this check, so "preregistered" has not been peer-reviewed.
7. **Sanders 2019 figures.** A published correction exists (Psychol Sci 2020;31(8):1048). Its content was not checked; a report that leans on exact Sanders numbers should confirm they are unaffected.
