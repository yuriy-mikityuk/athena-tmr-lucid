## Key question 3: REM detection — heuristic, personal classifier, reference-stager check, recorded numbers

### Takeaway
The wired detector is a six-feature weighted heuristic that the author's own analysis calls "effectively 1-feature"; the personal classifier is a numpy logistic regression stacked on the heuristic's sub-scores; the only accuracy numbers anywhere are from one EEG-only night versus GSSC (κ 0.30, REM recall 0.80, precision 0.30, gate open 35.7 % of epochs).

### Cited Findings
- Heuristic weights: `low_delta_power 0.25, theta_alpha_ratio 0.15, eye_movement_proxy 0.25, stillness 0.20, hr_variability 0.10, hr_trend 0.05`; thresholds: relative delta ≤0.35 → full REM score, ≥0.65 → zero; theta/alpha 0.70→1.40; eye proxy 0.05→0.20; stillness 0.85→0.97; RMSSD 15→80 ms; |HR trend| 5→40 bpm/min; caps: limited features → 0.55, motion arousal → 0.35; min coverage 0.30 per modality — [src/muse_tmr/models/heuristic_rem_detector.py](https://github.com/yuriy-mikityuk/remind-eeg/blob/main/src/muse_tmr/models/heuristic_rem_detector.py) lines 16–47.
- EEG bands delta 0.5–4, theta 4–8, alpha 8–12, beta 12–30, gamma 30–45 Hz — [src/muse_tmr/features/eeg_features.py](https://github.com/yuriy-mikityuk/remind-eeg/blob/main/src/muse_tmr/features/eeg_features.py) lines 17–23. Eye-movement proxy = `mean(|diff(AF7 − AF8)|)` in µV — same file lines 305–320.
- Author's finding (#116): per-epoch AUC vs GSSC-REM on `overnight_20260707`: `low_delta_power` 0.776, `stillness` 0.53, `eye_movement_proxy` 0.500 ("saturated: min = max = 1.0 for 100% of epochs"), `theta_alpha_ratio` 0.42 ("anti-signal"); 0.40 of total weight "going to a dead feature and an anti-signal" — [#116](https://github.com/yuriy-mikityuk/remind-eeg/issues/116) (open).

### Inferences
- The eye-movement proxy saturation follows directly from the code: `mean|diff(AF7−AF8)|` on real 256 Hz EEG is typically several µV, far above the `eye_movement_proxy_strong = 0.20` threshold, so `_high_score` returns 1.0 for every epoch; the thresholds look tuned for synthetic unit tests rather than real signal scale.
- The personal classifier's features are the heuristic's own outputs, so it cannot discover information the heuristic discards; it is a recalibration layer rather than an independent model.
- Precision 0.30 at recall 0.80 means roughly two of three gate-open epochs are non-REM by the GSSC reference; for a TMR system this is a large false-cue exposure and the author treats it as such (#116 open).

### Gaps
- No PSG- or expert-scored night exists; the author states this as a blocker in #116.
- No trained personal model artifact or its metrics is in the repo (private data policy), so the classifier's real-data performance is unknown.
- No REM-recall figure exists for any optics (`p1034`) night.

## Key question 5: TLR protocol fidelity vs Konkoly et al. 2021 / Carr et al. 2020

### Takeaway

## Key question 10: Honest gaps versus what comparable open-source projects typically offer

### Takeaway
Measured against the usual feature set of open sleep-EEG/closed-loop projects, REMind lacks standard-format export, cross-platform launchers, any published accuracy against PSG, EOG/eye-signal capability, closed-loop slow-oscillation stimulation, multi-user support, a PyPI release, a documentation site and any community beyond its author.

### Cited Findings
- No EDF/BDF/BIDS/MNE export: only CSV/Parquet feature rows and project JSON/JSONL; `.edf` is a forbidden pattern — [src/muse_tmr/features/eeg_features.py](https://github.com/yuriy-mikityuk/remind-eeg/blob/main/src/muse_tmr/features/eeg_features.py) lines 174–185; [scripts/check_forbidden_files.py](https://github.com/yuriy-mikityuk/remind-eeg/blob/main/scripts/check_forbidden_files.py).

### Inferences
- Strengths unique to this repo relative to typical hobby TMR/lucid-dream tools: layered, replay-testable safety gating with JSONL audit trails; seeded blind cued/uncued design with validator-enforced "no uncued play"; honest, numeric self-assessment of detector weakness in the tracker.
- Weaknesses that matter most for a fair comparison: scientific validation (n=1, automated proxy only, no audio night), interoperability (no EDF/BIDS), platform reach (macOS), and the stacked/saturated feature design of the REM model.

### Gaps
- No competitor was examined here (out of this researcher's scope); the "typical features" list is the comparison frame given in the assignment, not a finding about any specific project.
