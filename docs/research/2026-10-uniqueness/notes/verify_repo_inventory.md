## C. Technically true but misleading in context

1. **"VALIDATED" (A5).** `presets.py` and the inventory use the repository's own word. The `p21` thresholds were fitted on `overnight_20260707` and their 75 % → 36 % / recall ~0.80 effect is reported on that same night (`README.md` line 127: "fitted on one night"). This is in-sample tuning against an automated stager, not held-out validation. The report should say "tuned on one EEG-only night against GSSC", never "validated".
